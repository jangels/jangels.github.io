You'll find this post in your `_posts` directory. Go ahead and edit it and
re-build the site to see your changes.

The easiest way to preview locally is:

```bash
bundle install
bundle exec jekyll serve
```

Then open <http://localhost:4000>.

Jekyll requires post files to follow the format
`YEAR-MONTH-DAY-title.markdown`. Write the body in Markdown and add front
matter with at least `layout`, `title`, and `date`.
